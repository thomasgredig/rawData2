# rawData2

<!-- badges: start -->
<!-- badges: end -->

A package that generates unique identifiers, so that RAW files can be processed reproducibly on different platforms and in collaborations.

## Workflow

Reproducible RAW IDs are generated from files that will be static. These files are generally generated by instruments, such as XRD (.rasx), AFM (.tiff, .ibw, .nid) or similar instruments.

```{r}
raw.update(path)
```

This generates a file library in a directory called `.rawdata2`.
